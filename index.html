Does bad hospital data break chest X-ray AI? In progress

My dissertation. AI models that spot acute heart failure on chest X-rays are trained on clean images from large academic hospitals. Rural hospitals produce messier data: portable films, older scanners, missing metadata, inconsistent labeling. I'm measuring how that degradation changes model performance, using data quality dimensions from Wang and Strong and a sociotechnical view of how the data gets made.

Core experiments use public datasets (MIMIC-CXR and CheXpert), with a UAMS data partnership as a possible extension. Proposal outline and literature search strategy are complete.
